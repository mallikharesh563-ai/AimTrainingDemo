AIM TRAINING LAB - Android Studio project

Yeh ek standalone offline touch/aim practice simulator hai.
Yeh Free Fire ko modify, control ya connect nahi karta.

Features:
- Target par tap karke hits/shots/accuracy count.
- 80% accuracy sirf practice target hai, guaranteed headshot nahi.
- Freeze Demo: simulator ko pause karta hai.
- Ghost Visual: target ke aas-paas decorative glow dikhata hai.
- Reset Session.

APK banane ka tarika:
1. Android Studio install karo (computer par).
2. Is ZIP ko extract karo.
3. Android Studio > Open > extracted AimTrainingDemo folder.
4. Gradle sync hone do.
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK app/build/outputs/apk/debug/app-debug.apk mein milega.

Note: Android Studio/Gradle SDK ki zaroorat hogi. Phone par ZArchiver se source ko seedha APK mein convert nahi kiya ja sakta.
